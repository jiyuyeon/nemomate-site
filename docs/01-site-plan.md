# NemoMate 소개 사이트 — 기획서

> 작성일: 2026-04-07
> 버전: v1.0

---

## 1. 프로젝트 개요

### 목적
NemoMate 데스크톱 펫 게임의 **베타 버전을 소개**하고, 방문자가 **설치 파일을 다운로드**할 수 있는 원페이지 랜딩 사이트를 구축한다.

### 타겟 유저
- **1차:** 게임/캐릭터 콘텐츠에 관심 있는 20~30대 (귀여운 것을 좋아하는 사용자)
- **2차:** 데스크톱 커스터마이징에 관심 있는 사용자 (시메지, 데스크톱 펫 등)
- **3차:** 인디 게임/앱에 관심 있는 사용자

### 핵심 목표 (KPI)
| 지표 | 목표 |
|------|------|
| 베타 다운로드 수 | 첫 달 100+ |
| 페이지 체류 시간 | 평균 2분+ |
| 이탈률 | 60% 이하 |

## 2. 사이트 구조 (Information Architecture)

**형태:** 원페이지 스크롤 랜딩 + 고정 헤더

```
[Header] 로고 | 내비게이션 (소개 · 기능 · 스크린샷 · 다운로드 · 응원) | 언어(KR)

[Section 1: Hero]
  - 히어로 비주얼 (네모 캐릭터 + 방 배경)
  - 한 줄 카피 + 서브카피
  - CTA: 베타 다운로드 버튼

[Section 2: 소개]
  - 네모메이트가 뭔지 한눈에
  - 3~4개 핵심 가치 카드 (데스크톱 펫 · 인테리어 · 미니게임 · AI 채팅)

[Section 3: 기능 하이라이트]
  - 기능별 스크린샷/GIF + 설명 (좌우 교차 레이아웃)
  - 1) 네모와 대화하기 (AI 채팅)
  - 2) 방 꾸미기 (가챠 + 인테리어)
  - 3) 미니게임 (러너 게임)
  - 4) 네모 키우기 (호감도 시스템)

[Section 4: 스크린샷 갤러리]
  - 실제 게임 스크린샷 캐러셀/그리드

[Section 5: 다운로드]
  - OS별 다운로드 버튼 (macOS / Windows)
  - 시스템 요구사항
  - 베타 버전 안내 문구 + 로컬 데이터 안내

[Section 6: 응원 보내기]
  - 댓글 입력창 (닉네임 + 메시지)
  - 가이드 태그 (응원 · 버그 제보 · 아이디어)
  - Giscus (GitHub Discussions 기반 댓글 위젯)

[Section 7: Footer]
  - 저작권 · SNS 링크
```

## 3. 사용자 플로우

### 메인 플로우 (다운로드)
```
방문 → Hero 확인 → CTA 클릭 or 스크롤
  → 기능 섹션 탐색 → 다운로드 섹션 도착
  → OS 선택 → 파일 다운로드 → 완료
```

### 보조 플로우 (정보 탐색)
```
방문 → 내비게이션으로 원하는 섹션 이동
  → 스크린샷/기능 확인 → 다운로드 또는 이탈
```

## 4. 페이지 요구사항

### 필수 (MVP)
- [ ] Hero 섹션 + CTA 버튼
- [ ] 핵심 기능 소개 (최소 3개)
- [ ] 스크린샷/비주얼
- [ ] 다운로드 섹션 (macOS .dmg / Windows .exe)
- [ ] 반응형 디자인 (모바일 대응)
- [ ] 고정 헤더 + 스크롤 내비게이션
- [ ] 응원 보내기 섹션 (Giscus 댓글 위젯)
- [ ] 모바일 다운로드 대응 (PC 유도 안내)

### 선택 (Nice to Have)
- [ ] 네모 캐릭터 인터랙티브 애니메이션 (마우스 따라가기 등)
- [ ] 다크/라이트 모드
- [ ] 다국어 지원 (KR/EN)
- [ ] 뉴스레터/업데이트 알림 신청
- [ ] 방문자 수 카운터

- **브랜드 톤:** NemoMate 디자인 시스템의 따뜻한 브라운 톤 유지
