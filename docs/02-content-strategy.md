## 1. 톤앤매너

### 브랜드 보이스

- **따뜻하고 친근한** — 네모의 성격처럼 장난기 있고 귀여운 톤
- **간결하고 직관적** — 긴 설명 대신 한눈에 이해되는 카피
- **감성적** — 기능 나열보다 "네모와 함께하는 일상"이라는 감성 전달

### 카피 원칙

1. **제목:** 짧고 임팩트 있게 (한글 기준 10자 이내)
2. **본문:** 1~2문장으로 압축 (40자 이내)
3. **CTA:** 행동 유도형, 부드러운 어투 ("다운로드하기", "만나러 가기")
4. **네모 말투 차용:** 사이트 곳곳에 네모 캐릭터의 대사를 넣어 생동감 부여

### Section 3: 기능 하이라이트

각 기능은 **좌우 교차 레이아웃** (이미지 좌 + 텍스트 우 → 텍스트 좌 + 이미지 우)

#### 기능 1: AI 채팅

| 요소                | 내용                                                                              |
| ------------------- | --------------------------------------------------------------------------------- |
| **제목**      | "네모야, 오늘 어땠어?"                                                            |
| **본문**      | "네모는 당신의 말에 귀 기울이는 작은 친구예요. 기쁜 일도, 힘든 일도 함께 나눠요." |
| **비주얼**    | 채팅 UI 스크린샷 (네모 대화 장면)                                                 |
| **네모 대사** | "힘들었구나~ 내가 옆에 있을게~"                                                   |

#### 기능 2: 방 꾸미기

| 요소                | 내용                                                                                    |
| ------------------- | --------------------------------------------------------------------------------------- |
| **제목**      | "네모의 방을 꾸며주세요"                                                                |
| **본문**      | "가챠로 가구를 모으고, 드래그해서 원하는 곳에 배치하세요. 레벨이 오르면 방도 넓어져요!" |
| **비주얼**    | 꾸미기 모드 스크린샷 (가구 배치된 방)                                                   |
| **네모 대사** | "우와~ 예쁘다~!"                                                                        |

#### 기능 3: 미니게임

| 요소                | 내용                                                     |

| **본문**      | "러너 게임으로 코인을 모으고, 새로운 가구를 뽑아보세요." |
| **비주얼**    | 러너 게임 플레이 GIF/스크린샷                            |
| **네모 대사** | "슝~! 더 빨리~!"                                         |

#### 기능 4: 성장 시스템

| 요소             | 내용                                                                                         |

### Section 4: 스크린샷 갤러리

**섹션 제목:** "미리보기"

**필요한 스크린샷 목록:**

1. 게임 메인 화면 (네모 + 방)
2. 채팅 오버레이
3. 가챠 뽑기 연출
4. 꾸미기 모드
5. 러너 게임 플레이
6. 마켓 화면

**형태:** 가로 스크롤 캐러셀 (확정 — 모바일 스와이프 자연스럽고, 스크린샷 크기 통일 용이)
**스타일:** 스크린샷에 디바이스 프레임(맥북 모크업) 씌우기 → 실제 사용 느낌

### Section 6: 응원 보내기

**섹션 제목:** "네모에게 한마디!"
**서브 카피:** "버그 제보, 아이디어, 응원 메시지 뭐든 좋아요 :)"

| 요소 | 내용 |
| --- | --- |
| **댓글 입력창** | 닉네임(선택) + 메시지 텍스트 영역 + 전송 버튼 |
| **댓글 목록** | 최신순 표시, 닉네임 + 메시지 + 작성일 |
| **네모 반응** | 댓글 전송 시 네모 대사 "우와~ 고마워~!" 토스트 표시 |
| **가이드 태그** | 입력창 위에 클릭 가능한 태그: `응원` `버그 제보` `아이디어` (클릭 시 접두어 자동 삽입) |

**구현 방식 후보:**
- **A. GitHub Discussions 연동 (추천):** 별도 백엔드 없이 GitHub API로 댓글 CRUD. 정적 사이트와 궁합 좋음
- **B. Giscus:** GitHub Discussions 기반 오픈소스 댓글 위젯. 설정만으로 즉시 사용 가능
- **C. 자체 폼 + Google Sheets:** 폼 제출 → Google Apps Script → 시트 저장. 읽기는 수동

**네모 대사:** "뭐든 말해줘~ 나 다 듣고 있어~!"
